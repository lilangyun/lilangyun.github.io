# VSCode快捷键

由于经常使用VSCode编辑代码，因此记忆一些快捷键还是非常有必要的，就像是对于Vim来说，键盘才是编辑代码的唯一选择。

## 通用操作

| 功能     | Windows命令 |
| -------- | ----------- |
| 打开终端 | Ctrl + `    |
| 打开设置 | Ctrl + , |
| 新建窗口 | Ctrl + Shift + N |
| 关闭窗口 | Ctrl + Shift +W |
| 查找文件 | Ctrl + P |
| 开启/关闭侧边栏 | Ctrl + B |

## 文件操作

| 功能             | Windows命令       |
| ---------------- | ----------------- |
| 保存文件         | Ctrl + S          |
| 另存文件         | Ctrl + Shift + S  |
| 打开文件         | Ctrl + O          |
| 关闭文件         | Ctrl + W          |
| 新建文件         | Ctrl + N          |
| 切换至上一个文件 | Ctrl +Tab         |
| 切换至下一个文件 | Ctrl+ Shift + Tab |

## 代码操作

| 功能              | Windows/Linux          |
| :---------------- | :--------------------- |
| 撤销              | `Ctrl + Z`             |
| 重做              | `Ctrl + Y`             |
| 复制              | `Ctrl + C`             |
| 剪切              | `Ctrl + X`             | 
| 粘贴              | `Ctrl + V`             |
| 查找              | `Ctrl + F`             |
| 替换              | `Ctrl + H`             | 
| 全选              | `Ctrl + A`             |
| 注释行            | `Ctrl + /`             |
| 多行注释          | `Shift + Alt + A`      |
| 选中当前行        | `Ctrl + L`             |
| 查找替换          | `Ctrl + H`             |
| 转到行号          | `Ctrl + G`             |
| 在下方插入行      | `Ctrl + Enter`         |
| 在上方插入行      | `Ctrl + Shift + Enter` |
| 跳转到匹配的括号  | `Ctrl + Shift + \`     |
| 缩进/取消缩进     | `Ctrl + ] / [`         |

## 多光标操作

| 功能                | Windows/Linux        |
| :------------------ | :------------------- |
| 选择当前行          | `Ctrl + L`           |
| 选中所有匹配内容    | `Ctrl + Shift + L`   |
| 选中下一个匹配      | `Ctrl + D`           |
