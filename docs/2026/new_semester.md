# 大三新学期

又是新的学期，回过头来再看，竟然已经大三了，时间竟然如此之快。看到身边路过的穿军训服的少年们，我总是怀念我军训那段时光，那时候我身体素质很差，但是在母亲的陪伴下，我竟然撑了过去，也得到了很好的锻炼。**感谢母亲。**

## 身体状况

一到了秋季学期，由于**季节过敏性鼻炎**，我鼻子总是不舒服，我也不知道应该怎么调整。一旦我洗脸或是洗澡碰到鼻子，我就知道指定没好事。母亲常说，眼睛、耳朵、鼻子、喉咙是相通的，我真切地感受到了，因为我的眼睛也会时不时地敏感而不自觉地流眼泪。喉咙也时常干涩，或者是由于打喷嚏导致地发疼、发痒。

也许是空调坏的事，宿舍晚上经常开25度的空调，在我的争取下，给空调定时晚上2点关机。尽管如此，我的身体还是做出了它的回应，9月2日，被一股热流惊醒，来来回回上了3次厕所，腹泻来了。我赶紧买了肠炎宁，打算喝一天。**如果真的熬不过去，怎么也应该当回坏人，让舍友将就一下调高点温度或者是关闭空调睡觉。**

## 图书馆

由于身体原因，我总是愿意来图书馆，因为这里没有人会将就我，我也不需要将就别人。我可以穿很厚的衣服来享受空调，不必在意穿半袖的他人的目光。**图书馆收留了做[TCP实验](tju_tcp_lab.md)的我，我很感激，我得以在图书馆苟延残喘，等待花开的那一天。**

## 心理活动

尽管自己还是很羞涩，但是我勇敢地表达了我的想法，**我在睡觉前和舍友协商说开26度的空调**，最终温度虽然合适，甚至我已经感觉到暖和了，可是鼻子还是难受，肚子刚好但是还是有反应，总之，身体状态还没恢复好。**但是我并不知道舍友是否会觉得闷热，之后也应该问一下才好，我应该替别人着想，但是不应该替别人思考，否则就会内耗。**尽管我知道这样的道理，可奈何大脑仍然在疯狂地思考，别人是不是感到热了。大晚上的，我问也不是，不问也不是，于是我熬了许久，待到舍友都没了动静，我就下床去宿舍楼里慢慢走，慢慢平复心情。

说实话，我觉得舍友都能沟通，已经是一大幸事，但是有时候因为氛围、共同话题等原因，就觉得张口说话好像不合适，既会使别人尴尬，自己也会尴尬，我到现在也没有什么好的办法调节这一点，或许大家也都曾这么想过，但都和我一样无法付诸实践。**毕竟让别人进入自己的世界本来就是一件不容易的事情，宿舍里面的关系，也不必要如胶似漆那么热情美好，能够平等、合理表达自己的诉求就已经是最好的结果了。**

但对我来说，和大家协商说晚上把温度调到26度睡觉，本来是一件很合理的事情和诉求，可是自己就这么一直想后果、一直害怕别人评价、思考我，就这样把自己放在了庭审的聚光灯之下，让自己难做。我对自己也很无奈，但是我也接纳自己。我有时候觉得自己就像老鼠，因为我总瞻前顾后，试图躲避、逃避麻烦，但是我也不得不承认这个角色，剧本就是这么写的，内心想什么东西我怎么能控制得了。**我只能时刻告诉自己，要为自己的立场说话，要代表自己。**

## 过敏药

我还是和母亲说了我的身体问题，但同时我也才得知母亲最近鼻子也不舒服，这痛苦的季节过敏性鼻炎。母亲告诉我要买扑尔敏和维生素C，早晚各吃一次。我中午吃罢饭后，就吃上了药躺在床上休息，竟然睡了个好觉。起来之后鼻子好多了，25度的空调也能逐渐适应。世上只有妈妈好啊......**总结一下，一到9月份开学季，扑尔敏、肠炎宁是必备的，自己要牢记这点。**

身体出了这么多问题，其实心理也没好到哪里去，我意识到自己还是缺乏锻炼，之后开始逐步恢复锻炼吧，但是要避免剧烈运动，否则对眼睛、肺、鼻子都会带来负面效果。
