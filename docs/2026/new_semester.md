# 大三新学期

又是新的学期，回过头来再看，竟然已经大三了，时间竟然如此之快。看到身边路过的穿军训服的少年们，我总是怀念我军训那段时光，那时候我身体素质很差，但是在母亲的陪伴下，我竟然撑了过去，也得到了很好的锻炼。**感谢母亲。**

## 身体状况

一到了秋季学期，由于**季节过敏性鼻炎**，我鼻子总是不舒服，我也不知道应该怎么调整。一旦我洗脸或是洗澡碰到鼻子，我就知道指定没好事。母亲常说，眼睛、耳朵、鼻子、喉咙是相通的，我真切地感受到了，因为我的眼睛也会时不时地敏感而不自觉地流眼泪。喉咙也时常干涩，或者是由于打喷嚏导致地发疼、发痒。

也许是空调坏的事，宿舍晚上经常开25度的空调，在我的争取下，给空调定时晚上2点关机。尽管如此，我的身体还是做出了它的回应，9月2日，被一股热流惊醒，来来回回上了3次厕所，腹泻来了。我赶紧买了肠炎宁，打算喝一天。**如果真的熬不过去，怎么也应该当回坏人，让舍友将就一下调高点温度或者是关闭空调睡觉。**

## 图书馆

由于身体原因，我总是愿意来图书馆，因为这里没有人会将就我，我也不需要将就别人。我可以穿很厚的衣服来享受空调，不必在意穿半袖的他人的目光。**图书馆收留了做[TCP实验](tju_tcp_lab.md)的我，我很感激，我得以在图书馆苟延残喘，等待花开的那一天。**
