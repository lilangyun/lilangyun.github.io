# Vim学习

第一次接触 vim 是在2025年做 **nemu（南京大学模拟器）**的时候了解到的，知道这是一个终端上就能进行代码编辑的一个工具，但是因为其使用方式很困难，导致放弃。由于暑假最后有一段空闲时间，就重新补了一下 vim 使用技巧，主要是在**WSL**上使用**vimtutor**加上[missing-semester-vim](https://missing-semester-cn.github.io/2020/editors/)上的教程进行学习。

## 基本操作

### 移动

主要是使用**h, j, k, l**这4个键进行移动，其中`h`向左，`l`向右，`j`向下，`k`向上，可见下图：

```
** To move the cursor, press the h,j,k,l keys as indicated. **
             ^
             k              Hint:  The h key is at the left and moves left.
       < h       l >               The l key is at the right and moves right.
             j                     The j key looks like a down arrow.
             v
```

我的个人习惯主要是使用 **j键** 向下翻阅代码。但是使用这几个键进行移动实际上是没有鼠标滚动快速的，因此还可以搭配：

- `Ctrl + D`: 向下翻页
- `Ctrl + B`: 向上翻页
- `w`: 跳至下一个单词（word）
- `b`: 跳至当前单词词初（begin）
- `e`: 跳至当前词词尾（end）
- `0`：跳转至当前行初（注意是数字0）
- `$`：跳转至当前行尾

这样的确会快很多，但是仍然不够，在 **VS Code** 当中只需要滚动几下就可以找到目的位置，因此还需要更高效的定位方式。

### 查找

我仍然记得操作系统吴老师在实验课上直接使用 vim 进行 xv6 的实验演示，在其中我注意到他可以使用 vim 搜索一些关键代码片段从而跳转到对应位置，非常节省时间，搭配一些其他的定位键，效果极佳：

- `/{关键词}`：普通模式下键入`/{关键词}`就可以查找到文档中全部的关键词的位置（不需要键入`:`），并且可以使用 `n/N` 进行不同方向的位置切换。
- `gg`：跳转至文件头部位置
- `G`：跳转至文件尾部位置

### 编辑

其实[移动](#移动)和[查找](#查找)更多是从阅读代码的角度来提供便利，但是我们作为程序员最终还是要编写代码的。那么在编辑的过程中，我自己根据教程总结了几个比较常用的命令：

- 删除：
    - `x`：删除游标右侧第一个字符
    - `d`：进入删除模式，后续需要接收特定参数表示删除位置，可参考[移动](#移动)关于位置的指令

- 替换：
    - `r`：点击`r`之后，再键入目标字符，即可将游标右侧第一个字符替换
    - `R`：点击`R`之后，再键入目标字符串，即可替换游标右侧字符串

- 插入：
    - `i`：进入插入模式，可以编写任何代码
    - `o`：可以在游标所在行的下方进行插入空白行，并且进入插入模式
    - `O`：可以在游标所在行的上方进行插入空白行，并且进入插入模式

- 可视：
    - `v`：进入可视模式，这里的可视是指你可以选中代码，并且被选中的代码会高亮显示，因此很便于进行复制粘贴
    - `y`：复制
    - `p`：粘贴
